Baseline evaluation harness (#242): `evals/protocol.md` pre-registers a paired comparison of native Claude Code against the full hephaestus workflow — arms, endpoint, a behavior-only acceptance standard judged independently of the agent, the primary metric (paired acceptance rate), a 10-point non-inferiority margin for later candidates, and re-run triggers on model, harness, or workflow changes. `evals/run.sh` builds a fresh sandbox per run (repo at the task's base with no history, adapters stripped, isolated `HOME`, a `gh` that serves only the task issue), installs a pinned hephaestus that withholds the code under test for the full arm, shuffles runs by a recorded seed, and stops at a mandatory `--budget-usd`. Four seed tasks from this repository's own `collect-changelog.sh` bug history pass `evals/run.sh validate`, which proves each acceptance check rejects the unfixed base and accepts the upstream fix. No billed runs are made by this change.

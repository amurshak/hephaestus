Baseline evaluation harness (#242): `evals/protocol.md` pre-registers a paired comparison of native Claude Code against the full hephaestus workflow — arms, endpoint, a behavior-only acceptance standard judged independently of the agent, the primary metric (paired acceptance rate), a 10-point non-inferiority margin for later candidates, and re-run triggers on model, harness, or workflow changes. `evals/run.sh` builds a fresh sandbox per run (repo at the task's base with no history, adapters stripped, isolated `HOME`, a `gh` that serves only the task issue), clears the environment and disables web tools for both arms, installs a pinned hephaestus that withholds the code under test for the full arm, shuffles runs by a recorded seed, holds each run to a per-run spending cap within a mandatory `--budget-usd`, kills timed-out process groups, flags runs whose transcript touched the evaluation checkout or public repository, and reports acceptance with 95% intervals, cost per accepted run, and per-task discordance. Four seed tasks from this repository's own `collect-changelog.sh` bug history pass `evals/run.sh validate`, which proves each acceptance check rejects the unfixed base and accepts the upstream fix. No billed runs are made by this change.

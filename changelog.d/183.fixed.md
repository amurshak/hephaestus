**`collect-changelog.sh` ignored every argument after the first** (#183): a `case` on `$1` alone meant `collect-changelog.sh <version> --preview` matched the version, left the mode at `release`, and silently performed a real release — folding the fragments into `CHANGELOG.md` and deleting them. The same blind spot let any unrecognized flag (`--dry-run`, a typo, `-n`) reach the destructive default, since the unknown-flag guard also only checked `$1`. Arguments are now parsed in a loop: flags are position-independent, an unrecognized flag or a second positional exits non-zero without touching `changelog.d/` or `CHANGELOG.md`, and release is reachable only when no flag is given at all. `--preview` now also accepts a version and renders the dated heading the release would write, so previewing a specific version is a real rehearsal. Recoverable here only because the fragments were committed; mid-PR they are not, and target projects that adopted `--changelog-fragments` ship the same script.

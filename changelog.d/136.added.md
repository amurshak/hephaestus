**Changelog fragments for target projects** (#136): `install.sh --project|--vendor
--changelog-fragments` scaffolds `changelog.d/`, a `CHANGELOG.md` if absent, a copy of
`scripts/collect-changelog.sh`, and `CHANGELOG.md merge=union` in `.gitattributes`, so a
repo's changelog stops being the file every PR conflicts on. Opt-in, because unlike every
other scaffold it changes *where* `/ship` writes; sticky afterwards — later runs and
`update.sh` detect the adoption from the distributed script and keep it without the flag.
The copy is refreshed when it drifts from the clone, under `--force`.

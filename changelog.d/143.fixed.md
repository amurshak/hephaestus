Hermes adapters corrected against a live Hermes v0.15.1 install. The `/worktrees` spawn command was `hermes chat -q "/start-issue <N>"`, but single-query mode bypasses the slash-command dispatcher entirely, so the skill never loaded and the literal text reached the model; it now preloads the skill explicitly with `hermes chat -s hephaestus/start-issue -q "..."`. Delegate briefs no longer claim plain toolset "narrowing" — requested toolsets are intersected with the parent's and anything missing is dropped silently — and now state that a delegate inherits neither the parent conversation nor its working directory, so `context` must carry absolute paths. `verify-hermes-load.sh` checks the preload identifier the spawn depends on.

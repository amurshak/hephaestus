Hermes skills and delegate briefs no longer claim a delegate inherits "not your working directory" — a request dump (`HERMES_DUMP_REQUESTS=1`, Hermes v0.15.1) shows the child's prompt carries the parent's cwd twice, as a `Current working directory:` line and a `WORKSPACE PATH` hint. Both resolve from session-launch values that never track a mid-session move, so the wording now warns the inherited cwd is *stale* — frozen at launch, confidently wrong in a worktree — and the advice stands: put absolute paths in `context`. (The claim was introduced and corrected within the same release.)

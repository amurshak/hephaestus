**Stale-adapter sweeps no longer delete hand-written files** (#145): all four generators removed any unexpected file in a generated directory without checking for the `generated from` marker the skill sweeps already require. A personal command in `.claude/commands/`, agent in `.opencode/agents/`, role in `.codex/agents/`, or note in `.hermes/agents/` was deleted silently on the next sync. Each sweep now reports the file and exits non-zero instead, matching `check_stale_skills`. The issue named Codex and Hermes; the Claude and OpenCode generators had the same hole, and `.claude/commands/` is where users keep their own commands. Relatedly, the Claude and OpenCode generators printed `✓ adapters generated` and exited 0 even after reporting an error — they now exit non-zero like the Codex and Hermes generators, so a reported problem is never masked by a success line.

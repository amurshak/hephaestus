Verification evidence is bound to the revision it checked (#224). `/ship` now writes docs before any gate runs, runs gate commands directly with tools (a tester only for long or ambiguous output or independent acceptance checks), and reports an evidence table — check, command or method, outcome, and HEAD OID with tree state — in place of the generic "All tests passing / No regressions / Code critique: PASS" checklist. Tester, `/test-issue`, `/start-issue`, and `/ship` share one evidence-record contract: outcomes are passed, failed, blocked, not run, or not applicable; a record is reused only while nothing it reads (code, dependencies, configuration, environment, or docs for doc checks) has changed, so `/ship` no longer reruns what `/test-issue` just proved and never certifies a later unverified change. A draft PR now carries the changelog fragment written before its gates ran; it still never merges.

**Positioning stated as an open protocol** — hephaestus is an open protocol for agentic software development, not a workflow pattern with ports. The canonical specs in `.ai/` are the protocol and each harness gets a generated rendering of them, with no harness privileged. `.claude-plugin/plugin.json` and `CONTRIBUTING.md` say so directly, and the contributor recipe for a new harness now asks for both halves of conformance rather than one: a `--check` gate proves the rendering still matches the spec, and a `verify-<harness>-load.sh` proves a real install actually discovers and dispatches it. Only the first existed as stated guidance, which is how the Codex spawn form reached #139 resting on a documented signature nobody had run.

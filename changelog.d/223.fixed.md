Code critique no longer auto-passes lockfile-only changes (#223). The skip is decided by consequence rather than file type: only behavior-neutral whitespace or reader-facing prose that nothing executes or obeys bypasses the reviewer, while dependency manifests and lockfiles, CI/build/config, agent instructions (including CLAUDE.md, AGENTS.md, and generated adapters), and runbook or install steps are always reviewed. Dependency changes add a risk point, agent-instruction changes anywhere (not just `.ai/` and `.claude/`) add one, and the reviewer runs an explicit dependency assessment — moved packages and transitive versions, major bumps, manifest/lockfile agreement, install scripts, new registries, and known advisories.

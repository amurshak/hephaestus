**`install.sh --migrate`** (#131): converts a pre-2.2 submodule install in one command. Removes the `.hephaestus` submodule (deinit, `git rm`, the `.git/modules` entry, and `.gitmodules` when nothing else uses it) plus every symlink pointing through `.hephaestus/` in all four harness directories, then scaffolds the project-owned files. Project-owned content — `orient`, `AGENTS.md`, hooks, `CLAUDE.md` — is never touched. Implies `--project`; combine with `--vendor` to migrate straight to committed copies, and with `--audit` to preview. Idempotent: a second run reports nothing to migrate. Project-mode health check now also reports whether the shared set is present at user level, so a migrated repo says what is still missing.

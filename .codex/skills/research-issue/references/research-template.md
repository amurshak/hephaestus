# Research Template

## Summary

- 2-3 sentence direct answer.

## Key Findings

- Group by facet.
- Prioritize operationally relevant facts.

## Conflicting Viewpoints

- Note disagreements.
- State which position is better supported and why.

## Recommendations

- Provide concrete next actions.

## Sources

- Include authoritative URLs.
- Prefer official docs, specs, and primary sources.

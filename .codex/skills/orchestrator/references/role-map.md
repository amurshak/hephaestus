# Role Map

## Delegation Roles

- `explorer`: read-only codebase investigation and dependency tracing.
- `coder`: isolated implementation for focused task slices.
- `tester`: test/lint/build execution with structured summaries.
- `reviewer`: adversarial review for blocking and non-blocking findings.
- `researcher`: multi-source web research with confidence and citations.

## Delegation Guidance

- Parallelize only independent tasks.
- Keep each delegated task scoped to one purpose.
- Require structured outputs; do not return raw verbose logs.
